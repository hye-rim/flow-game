# 플로우 🔀

같은 색 점을 선으로 잇는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `puzzles.js` + `game.js`)입니다.

- **규칙**: n x n 칸에 색깔 점이 쌍으로 있다. 같은 색 점끼리 선(길)으로 잇는다. 길은 상하좌우로만 이어지고, 길끼리는 겹칠 수 없다. **모든 쌍을 잇고 빈 칸이 하나도 없어야** 클리어
- **퍼즐 34개**: 5×5 열 개(쉬움), 6×6 여덟 개(보통), 7×7 열 개(어려움), 8×8 여섯 개(아주 어려움). **모두 해가 하나뿐**이라 찍지 않고 추리로 풀 수 있다 (9×9 는 해가 하나뿐인 판이 무작위로는 거의 안 나와서 뺐다)
- 조작: 점(또는 이미 그은 길 위)에서 **끌어서** 긋는다. 손가락이 빨리 움직여도 지나간 칸을 건너뛰지 않는다. **다른 색 길 위로 지나가면 그 길이 그 칸에서 끊긴다**. 자기 길을 되짚어 가면 거기까지 지워진다. 이어진 길의 반대쪽 끝 점을 누르면 그대로 두고, 시작 점을 다시 누르면 그 색을 처음부터 다시 긋는다. 다른 색의 점은 지나갈 수 없다
- 화면: 연결한 쌍 수(`연결 3/5`)와 채운 비율(`채움 92%`), 이동 수(한 번 긋고 뗀 것이 한 번). 이은 점에는 흰 테두리, 이은 순간 반짝. ↩ 되돌리기(Z) · 💡 힌트(H, 틀리게 그은 색을 먼저, 없으면 하나를 정답 길로 놓아 준다) · 🔄 다시(R) · ☰ 퍼즐 선택. 완성하면 완성한 모양 미리보기가 나온다
- 가장 적은 이동 수는 `flowDone`, 로비에는 깬 퍼즐 수(`flowCleared`)가 보인다

규칙과 풀이는 `logic.js`(화면 없이 Node 로 시험), 퍼즐은 `puzzles.js`, 화면·입력·소리는 `game.js`.
**퍼즐 만들기** (`node tools/generate.js`, 크기마다 시간 상한이 있다): 판 전체를 한 번에 지나는 길을 무작위로 만들고(backbite) 몇 조각으로 자른 뒤, 길 끝의 칸을 이웃한 길로 옮겨 모양을 섞는다. 조각의 양 끝을 점으로 찍고 풀이기(`solve`: 가장 갈 곳이 적은 색부터 나아가며, 막힌 빈 칸과 이을 수 없는 색을 가지치기)로 **해가 정확히 하나인 것만** 남긴다.
시험은 `node --test`: `test/logic.test.js`(이웃·시작·나아가기·되돌아가기·끊기·점 지나기 금지·연결·완성 판정·이동 수·되돌리기·힌트, 34개 퍼즐이 모두 올바른 모양이고 **해가 하나뿐이며 저장된 정답과 같고** begin/extend 로 정답을 그대로 그으면 풀린다).
